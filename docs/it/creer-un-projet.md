# Creare un progetto

Nella Demo pubblica Freshdoc, all’indirizzo /GPTest/, il percorso illustrato utilizza l’interfaccia francese.

1. Apri la procedura guidata per la creazione del progetto e scegli il modello `Application web`.
2. Passa ai dettagli del progetto, inserisci il nome Portail client e seleziona le dimensioni del team.
3. Se viene visualizzato un errore relativo al nome, inserisci il nome prima di continuare. Passa alla schermata successiva, quindi conferma la creazione. Il messaggio `Votre projet est prêt.` e la descrizione `Portail client utilise le modèle Application web.` confermano il risultato.

## Riprendere l’inserimento dopo la chiusura

Nel percorso illustrato, chiudendo la procedura guidata dopo aver inserito il nome Portail client si apre la finestra di dialogo `Quitter la création ?`. Il pulsante `Continuer la saisie` consente di riprendere il percorso fino alla creazione.
