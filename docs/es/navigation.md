# Usar la navegación

En la interfaz en francés de esta demostración, la barra de navegación muestra Accueil, About, Services y Con.

1. Abra la página de inicio.
2. Localice el enlace Con en la barra de navegación.

Este enlace sirve como referencia visual en esta demostración; no ejecuta ninguna acción.
