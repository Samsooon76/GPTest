# Crear un proyecto

En la Demo pública de Freshdoc, en /GPTest/, el recorrido ilustrado utiliza la interfaz en francés.

1. Abra el asistente de creación de proyectos y elija la plantilla `Application web`.
2. Vaya a los detalles del proyecto, escriba el nombre Portail client y seleccione el tamaño del equipo.
3. Si aparece un error en el nombre, introduzca el nombre antes de continuar. Vaya a la pantalla siguiente y confirme la creación. El mensaje `Votre projet est prêt.` y la descripción `Portail client utilise le modèle Application web.` confirman el resultado.

## Reanudar la introducción de datos después de cerrar

En el recorrido ilustrado, cerrar el asistente después de introducir el nombre Portail client abre el cuadro de diálogo `Quitter la création ?`. El botón `Continuer la saisie` permite reanudar el recorrido hasta la creación.
