# Navigation verwenden

In der französischen Benutzeroberfläche dieser Demonstration zeigt die Navigationsleiste Accueil, About, Services und Con an.

1. Öffnen Sie die Startseite.
2. Suchen Sie den Link Con in der Navigationsleiste.

Dieser Link dient in dieser Demonstration als visueller Orientierungspunkt; er löst keine Aktion aus.
