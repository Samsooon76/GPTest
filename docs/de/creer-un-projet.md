# Ein Projekt erstellen

In der öffentlichen Freshdoc-Demo unter /GPTest/ wird der dargestellte Ablauf mit der französischen Benutzeroberfläche gezeigt.

1. Öffnen Sie den Assistenten zum Erstellen eines Projekts und wählen Sie die Vorlage `Application web`.
2. Wechseln Sie zu den Projektdetails, geben Sie den Namen Portail client ein und wählen Sie die Teamgröße aus.
3. Wenn ein Namensfehler angezeigt wird, geben Sie den Namen ein, bevor Sie fortfahren. Wechseln Sie zum nächsten Bildschirm und bestätigen Sie die Erstellung. Die Meldung `Votre projet est prêt.` und die Beschreibung `Portail client utilise le modèle Application web.` bestätigen das Ergebnis.

## Eingaben nach dem Schließen fortsetzen

Im dargestellten Ablauf öffnet sich beim Schließen des Assistenten nach der Eingabe des Namens Portail client der Dialog `Quitter la création ?`. Mit der Schaltfläche `Continuer la saisie` können Sie den Ablauf bis zur Erstellung fortsetzen.
