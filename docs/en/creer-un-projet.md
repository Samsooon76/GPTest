# Create a project

In the Freshdoc Public Demo, at /GPTest/, the illustrated flow uses the French interface.

1. Open the project creation wizard and choose the `Application web` template.
2. Proceed to the project details, enter the name Portail client, and select the team size.
3. If a name error appears, enter the name before continuing. Proceed to the next screen, then confirm the creation. The message `Votre projet est prêt.` and the description `Portail client utilise le modèle Application web.` confirm the result.

## Resume entering information after closing

In the illustrated flow, closing the wizard after entering the name Portail client opens the `Quitter la création ?` dialog. The `Continuer la saisie` button lets you resume the flow through to creation.
