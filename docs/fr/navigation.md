# Utiliser la navigation

Dans l’interface française de cette démonstration, la barre de navigation affiche Accueil, About, Services et Con.

1. Ouvrez la page d’accueil.
2. Repérez le lien Con dans la barre de navigation.

Ce lien sert de repère visuel dans cette démonstration ; il ne lance aucune action.
