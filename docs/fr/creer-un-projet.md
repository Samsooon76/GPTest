# Créer un projet

Dans la Démo publique Freshdoc, à l’adresse /GPTest/, le parcours illustré utilise l’interface française.

1. Ouvrez l’assistant de création de projet et choisissez le modèle `Application web`.
2. Passez aux détails du projet, saisissez le nom Portail client et sélectionnez la taille de l’équipe.
3. Si une erreur de nom s’affiche, renseignez le nom avant de continuer. Passez à l’écran suivant, puis validez la création. Le message `Votre projet est prêt.` et la description `Portail client utilise le modèle Application web.` confirment le résultat.

## Reprendre la saisie après une fermeture

Dans le parcours illustré, la fermeture de l’assistant après la saisie du nom Portail client ouvre la boîte de dialogue `Quitter la création ?`. Le bouton `Continuer la saisie` permet de reprendre le parcours jusqu’à la création.
